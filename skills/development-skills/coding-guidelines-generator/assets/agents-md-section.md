## Stack Guidelines

Read the relevant stack guideline file when touching its domain:
- Read `./AGENTS-GUIDELINES-JS.md` when working on JavaScript / TypeScript code.
- Read `./AGENTS-GUIDELINES-REACT.md` when working on React components.
- Read `./AGENTS-GUIDELINES-NEXTJS.md` when working on Next.js routes, server actions, or configuration.
- Read `./AGENTS-GUIDELINES-PYTHON.md` when working on Python services, scripts, or APIs.
- Read `./AGENTS-GUIDELINES-PHP.md` when working on PHP backend code.
- Read `./AGENTS-GUIDELINES-WORDPRESS.md` when working on WordPress themes, plugins, or hooks.
- Read `./AGENTS-GUIDELINES-ANDROID.md` when working on Android app or library modules.
