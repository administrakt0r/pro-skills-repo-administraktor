# Coding Guidelines Generator

Deterministic router for generating and maintaining modular stack guidelines.

## Routing Table

## Conflict Policy
Stack guidelines may only be stricter than the portable baseline on security,
authorization, data protection, and verification. They never weaken baseline rules.
Material conflicts must be surfaced to the user, never silently resolved.

## Monorepo Collision Resolution
- If a package directory has its own `AGENTS.md`, write guideline files next to it.
- Otherwise, generate one guideline file per stack next to root `AGENTS.md`,
  listing the directories it covers.

## Execution Workflow

1. **Read Environment**: Inspect existing `AGENTS.md`, `CLAUDE.md`, manifests, and
   git status. Never overwrite uncommitted user changes. If not a git repo, note it.
2. **Detect Stack**:
   - Run `python3 scripts/detect_stack.py --root .`
   - *Manual Fallback* (if `python3` missing): Check signature files from Routing Table
     manually. Treat `package.json` in PHP/WordPress/Android as secondary tooling.
3. **Confirm or Ask**: Present detected stacks, versions, real commands, and target
   paths in one concise message. If ambiguous, ask once. Support dry-run (`--dry-run`),
   refresh, and remove (`--remove`) modes. Never write before confirmation.
4. **Baseline Check**: If `AGENTS.md` lacks the portable baseline, propose adding
   `assets/baseline.md` (150-250 words, merged additively).
5. **Generate Guidelines**:
   - Generate each required guideline file for detected stacks (including full layer chains: e.g. Next.js generates JS, React, and Next.js files; WordPress generates PHP and WordPress files).
   - Each layer contains only its own layer's rules and names lower layers in one line.
   - Upsert content between marker pair:
     `<!-- stack-guidelines:start skill=1.1.0 verified=YYYY-MM-DD hash=<hash> -->`
     using `scripts/upsert_section.py --file <path> --content-file <ref> --hash --substitute pm=<pm>`.
   - Never alter text outside the markers.
6. **Link from AGENTS.md**: Upsert managed section using the dynamic links generated by
   `detect_stack.py` (or templating `assets/agents-md-section.md` with only detected files)
   between `<!-- stack-guidelines:start -->` and `<!-- stack-guidelines:end -->`.
   Never link to ungenerated stack files. Place at the bottom by default (ask if top preferred).
7. **Report**: Summarize detected stacks, created/updated files, hash status, and
   unverified items. Re-running on unchanged code is byte-identical.
